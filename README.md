# Credit Scoring App – Hackathon Project

**Credit Scoring App** was developed during the **Google Developer Groups (GDG) Cairo Hackathon – February 2024**.  
Built in just 24 hours, this Android application leverages **AI-powered credit evaluation** to provide smarter, faster, and fairer credit scoring.  

---

## Key Features

- **AI-Driven Credit Scoring**: Integrated with **Gemini API** to evaluate users’ creditworthiness intelligently.  
- **Modern UI**: Built with **Jetpack Compose** for a sleek, user-friendly design.  
- **Seamless API Integration**: Uses **Retrofit** for efficient and reliable backend communication.  
- **Real-Time Results**: Provides instant credit evaluation to enhance user decision-making.  
- **Collaboration Ready**: Developed in partnership with a teammate during the hackathon.  

---

## Technologies Used

- **Kotlin** – Android native development  
- **Jetpack Compose** – Modern UI framework  
- **Retrofit** – Networking and API calls  
- **Gemini API** – AI-powered credit scoring  
- **GitHub** – Version control & collaboration
